# InputMethodEditor

Windows 中文輸入法，核心是 [libchewing](https://codeberg.org/chewing/libchewing)（新酷音）。
可以打注音或漢語拼音（含雙拼），會自動學習你常用的詞，學到的詞所有程式共用。

## 功能

**打字**

* 注音：新酷音的智慧選字、選字修正與自動學習；也可以不打聲調連著打，`ㄋㄧㄏㄠ` 就是「你好」，
  或只打聲母，`ㄐㄊㄊㄑㄏㄏ` 是「今天天氣很好」（見[注音](#注音)）
* 漢語拼音：連打不用分隔、簡拼、模糊音，也可以用雙拼（小鶴、自然碼、微軟、搜狗），同樣會自動學習（見[拼音](#拼音)）
* 罕用字：新酷音詞庫沒有的字（例如「䨻」）從 Unicode 的 Unihan 資料庫補上約 2 萬字，用臺灣的讀音，排在候選字最後；
  其中約 1 萬 4 千字在擴充 B 區以後（例如「𥩙」），字型沒有收錄的會顯示成方框
* 正體／簡體輸出切換，可選擇只轉字形（軟體→软体）或連用語一起轉（軟體→软件）
* 自訂詞組：定義縮寫，例如打 `addr` 再按空白就輸入整段地址
* 符號：按 `` ` `` 叫出符號表（鍵可以換或關掉），或用 Shift＋字母直接輸入常用符號，兩者內容都可以自己改；
  也可以用 Ctrl＋標點鍵打全形標點，不必按 Shift
* 打字列：打的字先出現在游標下方的小視窗，選好送出才進到程式裡，像自然輸入法

**順手**

* 每個程式記住自己的中文／英文，也可以指定某些程式固定用英數或中文
* 可調整候選字數、字型與顏色、鍵盤配置（標準、許氏、倚天、Dvorak 等）、快捷鍵；按「套用」後，下一個按鍵就生效
* 自動檢查新版本，同意後在背景更新，不用關掉開著的程式

**詞庫**

* 使用者詞庫編輯器：檢視、新增、刪除學到的詞，調整偏好程度；存檔不會蓋掉編輯期間其他程式學到的詞
* 匯出／匯入詞庫，搬到另一台電腦；也能匯入其他新酷音的 `user_dict.csv`

## 系統需求

Windows 10／11 x64。在 ARM64 版 Windows 上只能用於 x64／x86 程式。

## 安裝

執行 `InputMethodEditor.msi`，在 UAC 視窗按「是」。它會裝到
`C:\Program Files\InputMethodEditor`，並把輸入法加到你的語言清單；
已開啟的程式要重新開啟才能使用。安裝需要系統管理員權限。

## 開始使用

1. 按 Win＋Space（或從工作列右下角的語言圖示）切換到 InputMethodEditor，工作列會出現「中」圖示
2. 直接打注音，按空白或聲調鍵組字，按 Enter 送出；要選別的字時把游標移到詞的前面按 ↓ 開啟候選字
   （在「設定 → 打字行為」勾選「游標在詞的後面選字（macOS 方式）」就改成游標放在詞的後面）
3. 按 Shift 切換中文／英文（英文模式時圖示是「英」）；在圖示上按左鍵也可以切換
4. 在「中」圖示上按**右鍵**，開啟選單：

| 選單項目 | 功能 |
|---|---|
| 新酷音使用說明 | 注音輸入的完整操作說明（網頁） |
| 編輯使用者詞庫 | 開啟使用者詞庫編輯器 |
| 設定 | 開啟設定程式 |
| 網路辭典 | 開啟萌典或教育部辭典網站 |
| 輸出簡體中文 | 切換正體／簡體輸出 |
| 簡體改用大陸用語 | 簡體輸出時連用語一起轉，例如 軟體→软件 |

### 開啟設定

* 在工作列「中」圖示上按右鍵 → 「設定」
* 或按 Win＋R，輸入 `inputmethodeditor-settings://open` 後按 Enter（輸入法還沒切換過去時可以這樣開）

改完按「套用」立即生效、「確定」生效並關閉、「取消」放棄修改。
「還原此頁預設值」把目前分頁改回預設，同樣要按「套用」或「確定」才生效。各分頁的內容：

| 分頁 | 內容 |
|---|---|
| 打字行為 | Shift／CapsLock 切換中英文、標點與符號（Shift 或 Ctrl 打全形標點、快捷符號）、選字鍵與選字時游標在詞的前面或後面（macOS 方式）、注音模式（逐字、智慧選詞、可省略聲調連打）、打字列、自動學習、簡體輸出等 |
| 各程式 | 指定程式固定用英數或中文 |
| 界面外觀 | 候選字個數、字型、文字大小、深色／淺色／自訂顏色 |
| 鍵盤設定 | 注音鍵盤配置：標準、許氏、IBM、精業、倚天、大千 26 鍵、Dvorak、Colemak 等 |
| 拼音 | 拼法（全拼或雙拼方案）、模糊音 |
| 自訂快捷鍵 | 把按鍵綁到輸入文字、切換簡體、切換許氏鍵盤、切換注音／拼音、忘掉詞彙 |
| 特殊符號 | 叫出符號表的鍵（預設 `` ` ``，可換或關掉）與符號表 |
| 快捷符號 | Shift（或 Ctrl＋Shift）＋字母對應的符號或文字 |
| 自訂詞組 | 縮寫與對應的文字 |
| 更新與記錄 | 自動檢查更新的開關、間隔與「立即檢查更新」；問題記錄的等級與「開啟記錄檔資料夾」（見[問題記錄](#問題記錄)） |

### 按鍵

| 按鍵 | 功能 |
|---|---|
| Shift | 切換中文／英文 |
| Ctrl＋Space | 關閉／開啟輸入法（關閉時工作列圖示是 ⊗）；關閉時按 Shift 也會開啟並回到中文 |
| Shift＋Space | 切換半形／全形，全形時英文字母、數字、空白也是全形（ＡＢＣ１２３）；需先在「設定 → 打字行為」開啟 |
| Ctrl＋, . / ; ' [ ]（中文模式） | 打全形標點：，。／；、「」；需先在「設定 → 打字行為」開啟，開啟後這些組合在中文模式不再交給程式（例如 VS Code 的 Ctrl＋/） |
| Ctrl＋F11 | 切換注音／拼音 |
| Ctrl＋F12 | 切換正體／簡體輸出 |
| Ctrl＋Delete（選字時） | 忘記選中的詞，不再優先出現 |
| ˊ ˇ ˋ ˙（注音組字中） | 改掉游標前一個字的聲調，例如「嗎」按 ˇ 變「馬」；可先用 ← → 移動游標 |
| 空白（注音組字中） | 同上，改成一聲，例如「大」變「搭」；連按兩下則是插入空白，字不變 |

中文模式打的標點是全形（，。？），英文模式是半形。
注音／拼音與正體／簡體設定是所有程式共用。

### 中文／英文與各程式

每個程式記住自己的中文／英文：例如在 Chrome 切成英文、Telegram 維持中文，重新開啟後也一樣；
還沒切換過的程式照「設定 → 打字行為」的「預設以英文模式啟動」。

也可以在「設定 → 各程式」指定程式固定用英數或中文（例如 chrome.exe 用英數）：開啟或切換到它時就換過去。
執行檔名稱可以自己輸入，或按「從程式清單加入」從開始功能表與開著的程式裡一次勾選多個；
用 CapsLock 切換中英文時也有效（會自動按一下 CapsLock，讓燈號和模式一致）。

### 注音

預設是「智慧選詞（每個字打聲調）」：每個字打完聲調（一聲按空白）就會轉成中文，整句打完再按 Enter 送出，
新酷音會依上下文自動選詞。注音的其他操作見右鍵選單的「新酷音使用說明」。

**連打**：在「設定 → 打字行為」的「注音模式」選「智慧選詞（可省略聲調，連打）」，就能像拼音一樣不打聲調連著打：
`ㄋㄧㄏㄠ` 是「你好」，`ㄐㄧㄣㄊㄧㄢㄊㄧㄢㄑㄧㄏㄣㄏㄠ` 是「今天天氣很好」，最後一個字按空白、Enter 或標點結束。
也可以像拼音簡拼一樣只打聲母：`ㄐㄊㄊㄑㄏㄏ` 是「今天天氣很好」，`ㄓㄍ` 是「這個」，可以和完整的字混著打（`ㄐㄧㄊ` 是「集團」）。
要指定聲調照樣打 ˊ ˇ ˋ ˙；但空白在這個模式不限定一聲，例如 `ㄉㄠ` 加空白可能是「到」而不是「刀」，
習慣每個字都打聲調的話，用預設模式比較準。

### 拼音

按 Ctrl＋F11，或在「設定 → 打字行為」勾選「以漢語拼音輸入」切換到拼音。
直接連著打，不用標聲調：`nihao` 是「你好」，`wojuedezheyangbucuo` 是「我覺得這樣不錯」。
打字的同時就會轉成中文，最後一個字按空白、標點或 Enter 結束。

* 音節分不清時用 `'` 隔開：`xian` 是「現」，`xi'an` 是「西安」；
  a、o、e 開頭的字接在別的字後面時照拼音規則要加 `'`，例如 `ping'an`（平安）
* 簡拼：只打聲母，`zhg` 是「這個」，`bj` 是「比較」
* 要指定聲調就在音節後按 2～5，例如 `ma3` 是「馬」
* ü 打成 `v`：`nv` 是「女」，`lvse` 是「綠色」
* 模糊音：在「設定 → 拼音」勾選分不清的音（z/zh、c/ch、s/sh、n/l、f/h、r/l、an/ang、en/eng、in/ing），
  打哪一個都找得到兩邊的字，例如勾選 z = zh 後 `zongguo` 是「中國」；
  勾選 r = l 後，`len` 這種原本不是音節的拼法也可以打（「人」）
* 雙拼：在「設定 → 拼音」的「拼法」選小鶴、自然碼、微軟或搜狗雙拼，每個字打兩鍵（聲母鍵、韻母鍵），
  打完第二鍵就轉成中文，例如「雙拼」小鶴是 `ulpb`，其他三種是 `udpn`。
  沒有聲母的字照各方案的打法：小鶴、自然碼 `ai`（愛）、`ah`（昂），微軟、搜狗 `ol`、`oh`。
  只打聲母鍵再按空白是簡拼；雙拼不標聲調，也不用 `'` 分隔

### 自訂詞組

在「設定 → 自訂詞組」每行寫一個「縮寫 文字」，例如 `addr 臺北市信義區市府路 1 號`，按「套用」。
之後在沒有組字時打 `addr` 再按空白，就換成那段文字；注音、拼音、雙拼都適用。
縮寫只能用英文字母；和拼音相同的縮寫（例如 `wo`）會取代原本的字，所以建議用不是拼音的組合。`#` 開頭的行是註解。

### 符號

* 中文模式按 `` ` `` 叫出符號表，分類與內容在「設定 → 特殊符號」修改，每行是「分類名稱=此分類下的所有符號」；
  常要打 `` ` `` 本身的話（例如寫 Markdown），在同一頁換成別的鍵或取消勾選，之後 `` ` `` 就照常打出來
* 中文模式按住 Shift＋字母直接輸入對應的符號或文字，對應表在「設定 → 快捷符號」修改，每行是「大寫字母 符號或文字」；
  要改用 Ctrl＋Shift＋字母，在「設定 → 打字行為」切換

### 打字列

在「設定 → 打字行為」勾選「使用打字列」後，打的字先出現在游標下方的小視窗，候選字開在它下面，
按 Enter（或選好字）送出時才進到程式裡，像自然輸入法。適合不顯示組字的程式（遊戲、部分終端機），
或不想讓組字中的字影響文件排版時。切到別的視窗時，打字列裡的字會直接送出。

### 使用者詞庫

在「中」圖示上按右鍵 → 「編輯使用者詞庫」，可以檢視、新增、刪除學到的詞，調整偏好程度（-100～100），改完按「存檔」。

要把詞庫搬到另一台電腦：用編輯器的「檔案 → 匯出詞庫」存成 CSV，在另一台用「匯入詞庫」合併進去
（兩邊都有的詞取較高的偏好程度）；也能匯入其他新酷音的 `user_dict.csv`。只含詞，不含選字習慣的統計。

## 更新

每次登入 Windows 後，以及距離上次滿 7 天時（登入或中午），會看 GitHub 上有沒有新版本，有的話詢問要不要下載安裝；
可在「設定 → 更新與記錄」取消登入時的檢查、把間隔改成 1～30 天，或關閉自動檢查；要馬上更新就按同一頁的「立即檢查更新」。
同意後除了 UAC 不會再跳出其他視窗，開著的程式不用關，之後開啟的程式就會用新版。
同一時間只會進行一個更新；更新失敗時保留原本的版本，詳細原因記在 `%TEMP%\InputMethodEditor-install.log`，回報問題時請附上。

0.5.0（含）以前的版本自動更新失敗後，輸入法可能整個不見；這時請下載最新的 `.msi` 重新安裝，詞庫與設定都還在。

也可以直接執行新版的 `.msi` 更新；這時若出現「下列應用程式應該被關閉」，按「略過」即可；
移除舊版時會再問一次（可能是英文），同樣按「Ignore」。

## 問題記錄

輸入法把錯誤與警告寫在 `%AppData%\InputMethodEditor\ime.log`（超過 1 MB 時舊的改名成 `ime.old.log`）。
要回報問題時，在「設定 → 更新與記錄」把「記錄等級」調高（info 記狀態變化，debug 再加上按鍵與打出的字，trace 全部），
按「套用」後重現問題，再按「開啟記錄檔資料夾」附上記錄檔。用完請改回 warn。

## 移除

在「設定 → 應用程式 → 已安裝的應用程式」移除 InputMethodEditor。
若出現「下列應用程式應該被關閉」，按「略過」即可：開著的程式到關閉前仍用舊的輸入法，檔案在重新開機後刪除。
移除不會刪除使用者詞庫與設定，
分別在 `%AppData%\InputMethodEditor` 與 `HKEY_CURRENT_USER\Software\InputMethodEditor`，
不需要時請手動刪除。

## 隱私

本程式不會把任何資料傳送到網路上的其他系統，除非使用者或安裝、操作它的人明確要求。

唯一的例外是檢查更新：登入時、依「設定 → 更新與記錄」的間隔，以及按「立即檢查更新」時連到 `api.github.com` 查詢最新版本，
同意更新後再從 GitHub 下載安裝檔。這些連線不帶任何你的資料，但 GitHub 看得到你的 IP 位址。
不想連線的話，在同一頁取消「自動檢查更新」。

問題記錄只存在本機。記錄等級設成 debug 或 trace 時，記錄檔裡有你打的每個鍵和字，附給別人前請先看過；預設的 warn 不記錄這些。

為了讓開始功能表搜尋與 Microsoft Store 應用程式也能使用與學習詞彙，
使用者詞庫資料夾開放給這些應用程式讀寫；也就是說，它們讀得到你學過的詞。
